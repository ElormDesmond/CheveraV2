CheVera V2 The Architect's Canvas

This project is a modern web application for CheVera Company Limited. It is built with React 19 and Go Fiber.

Structure
The project is divided into a web client and a backend API. The web client handles the user interface and interactions. The backend API manages data and security protocols.

Setup Instructions
Navigate to the web client directory to install dependencies. Run the development server to view the website locally. Use the provided Docker Compose file to start the entire system including the database.

Deployment
The frontend is optimized for static hosting on platforms like Vercel. Follow the included deployment guide for production setup.
